# OpenOS 与 Plan9k 安装和启动

C13/C14 使用唯一固定上游提交
`258943363ea8fc4ef14948e6bc6f67375061580c` 中的 Lua BIOS、OpenOS、Plan9k、
安装程序及其全部系统资源。运行的是原系统，没有用简化 shell 或测试固件替代。
Lua、文档、系统程序及其原许可和署名继续随模组保留。

有限验收在两个独立的实际机箱中并行进行，均使用普通三级机箱、原生 Lua 5.3
CPU、实际内存、硬盘、显卡、屏幕、键盘、Lua BIOS 和对应的只读安装软盘。
测试通过公开屏幕输入接口，把普通单行命令交给真实物理键盘和权限检查，再由
原系统处理。服务器玩家使用本地测试传输，客户端往返仍归 C19。

OpenOS 使用原 `install --from=... --to=... --noreboot` 及确认输入；Plan9k
使用原 `install`、硬盘选择和离线发行版选择，由原 MPT 安装所选系统。
安装后先正常关机，再实际取出安装软盘，重新开机并检查 EEPROM 选择原硬盘。
随后由硬盘上的系统执行 mkdir、重定向 echo、cp、mv、cat、ls、Lua 脚本及 rm。
原 reboot 程序再次启动系统，最后正常关机并从真实硬盘读取结果，验证命令数据
跨重启保留。终端输出和机器启动/停止事件同时记录。

该场景只由真实程序安装系统，不在 Java 中复制系统文件，不预写期望结果。
供电由实际连接器提供，使用默认资源预算；没有关闭内存、调用预算或执行时限。
所有方块、磁盘和账户均属于隔离测试世界，结束后清理。
