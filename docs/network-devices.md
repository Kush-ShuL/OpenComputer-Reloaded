# 网络设备

本族保留 D05 线缆、D26 网络分离器、D27 有线网卡、D35 中继器及 D61 两级无线网卡。
唯一语义来源为 MightyPirates/OpenComputers 固定提交
`258943363ea8fc4ef14948e6bc6f67375061580c` 中对应的方块、物品、驱动和组件，
及 `Colored`、`OpenSides`、`RedstoneAware`、`Hub`、`ComponentInventory`、
`WakeMessageAware` 与 `WirelessNetworkCardHandler`。保留上游许可证与归属。

D05 使用不可寻址的线缆节点、原分段碰撞形状和 OC 调色板。浅灰色 `0xABABAB`
可连接任意颜色，其他颜色必须相同；改色后重新连接并同步外观。原生染料及标准染料
标签可直接给已放置的线缆染色，非创造模式每次消耗一份。默认色掉落、选取不附带
染色数据，其他颜色跟随物品保留。方块保存使用原 `oc:renderColorRGB`，并能读取原
`oc:renderColor` 色号及本移植先前的 `oc:color`。外观连接沿用原机器人代理例外，
并尊重已有分面连接限制；旧微型方块模组的外部适配仍归相应可选集成处理。

D26 保留六侧原始开关和红石反转，脚本读取有效状态，`setSides` 返回修改前状态，
`open`、`close` 返回该侧是否改变。越界方向返回 `nil, "invalid direction"`。
普通红石输入的变化控制反转，集束通道不能替代普通信号。加载保持已存反转状态，
随后按原输入缓存的变化更新；手动切换和反转分别播放原伸出、收回声效。
改变连接时移除并重建真实网络节点，原始开关、反转和节点信息持久化。

D27 保留端口 1 至 65535、重复开关的返回值、各卡端口数量限制和原报错。
发送、广播、源地址和目标地址过滤、`modem_message` 参数及唤醒消息均沿用原规则。
唤醒不受端口是否打开限制；普通消息仍要求端口已打开。邻接计算机启动、停止或网卡
自身断开时关闭端口。存档中的端口完整恢复，不因降低配置上限丢失；上限仍约束新开端口。
机架使用邻接范围发送有线流量，其余宿主使用可达范围。

D61 一级卡只收发无线流量，二级卡同时支持有线流量；两级保留各自最大范围、费用和
端口数。无线发送按实际强度扣能，强度为零时不发送无线数据；设置强度按原上下界截取。
接收距离使用原宿主坐标算法，已打开端口的接收还受卡的最大范围限制。
连接、卸载、每二十刻及机器人移动事件维护无线索引。二级卡即使使用网络可达节点，
其机架有线发送仍保持原邻接范围。强度、端口、唤醒设置和节点地址随物品保存。

D35 六侧网络彼此隔离，每个相连网络只暴露对应的主转发端口，保留跳数、队列上限、
转发间隔、每批数量及二十周期统计。CPU、内存、硬盘分别提升延迟、吞吐和队列；
无线卡、链接卡保留原无线重发与隧道转发费用。更换硬件不重置用户设置的强度，
恢复存档时保留已有待转发包，降低上限仅约束新入队。初始强度沿用原构造顺序产生的
一级无线范围，`setStrength` 与加载强度时再按已安装硬件截取。

中继器插入硬件时经真实驱动加载和保存私有环境，移除及掉落前保存最新物品状态，
保留原生命周期通知。这些环境按原版不接入六侧转发网络，不把硬盘或网卡额外暴露
成可用组件。已有 ComputerCraft 转发入口继续使用同一个队列和包监听入口。

Windows NeoForge 21.1.224 批次 `device-batch-20261027-c3` 已通过真实设备验证：
三段线缆连接、染料耗用、颜色隔离/通配重连及默认色掉落；真实有线卡的二进制包、
端口恢复/关闭/拆除；两级无线卡在独立 Case 图之间二格距离的真实收发及配置费用；
中继器强度 7 在 CPU 和无线卡替换后保留，卡自身的强度与唤醒数据独立保存。

分离器恢复原非 Tickable 的同步初样和邻居采样。实测先由公开保存数据确认六侧
真实零输入，再用红石块形成 15 输入并隔离原已打开的两面，去电后恢复原网络。
保留首样不触发变化事件的规则，集束输入不会控制普通红石反转。
