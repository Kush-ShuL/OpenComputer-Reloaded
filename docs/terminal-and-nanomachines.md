# 无线终端与纳米机器

无线终端先在机架内的终端服务器上绑定，再手持终端打开。每个服务器保留最近四把密钥；旧密钥被替换后需要重新绑定。切换手中物品、死亡、离开对应维度或达到无线距离上限会断开连接。终端保留原版独立显示文本的行为，并支持键盘、粘贴及触摸输入。

纳米机器食用后安装，配置物品保留其地址和行为连接，再次安装时不会自动启用输入。硫酸可卸载。内置行为包括药水效果、粒子、饥饿、磁力和方块分解；其他模组可通过公开的 BehaviorProvider 接口添加行为。

输入数量、同时启用数量、安全数量、耗能、回复端口和命令延迟遵循配置。达到启用上限时，再次设置任意输入为启用也会返回失败。无电时暂停行为，恢复供电后重新启用；卸载时，行为的停用回调仍能查询原控制器。

网络协议沿用原版字节字符串 `nanomachines` 开头的命令及原有回复格式。为保留指定上游版本的实际行为，纳米机器的有效命令半径和回复的无线费用均使用 `commandRange` 配置值的平方。例如配置 2 对应半径 4；这与无线终端的普通半径不同。

实现依据 MightyPirates/OpenComputers 提交 `258943363ea8fc4ef14948e6bc6f67375061580c`。保留现有公开 API、提供器标识、配置物品和 `.ocnm` 存档格式。终端会话使用本移植的快照和增量同步；客户端显示、远程多人操作与完整视觉验收随共用客户端批次进行。
