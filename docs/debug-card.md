# 调试卡

本族仅对照 MightyPirates/OpenComputers 提交
`258943363ea8fc4ef14948e6bc6f67375061580c` 的调试卡、驱动、绑定数据和
`DebugCard` 组件及值对象，保留原有许可证和署名。

## 绑定和权限

潜行右键绑定到当前玩家，再次使用解除自己的绑定。白名单模式下，未获授权的
玩家不能绑定。`oc_debugWhitelist` 管理授权和撤销；撤销会使旧卡和已经取得的
世界、玩家、计分板对象同时失效，重新绑定后才能继续使用。

所有受权操作保留原版能力，不另加管理员门槛。执行命令仍使用绑定玩家的
实际权限、身份和坐标；卡所在世界作为命令的世界。单人游戏沿原版授予命令
权限。未绑定或绑定玩家离线时，命令使用原配置的假玩家。

卡只有保存了节点地址才限制单件堆叠；普通绑定本身不改变原来的堆叠上限。
保留普通稀有度、短地址说明和禁止书附魔。

## 提供的操作

组件可查看位置、世界和在线玩家、调整网络能量、执行命令、扫描指定位置、
连接远处的组件，以及向调试卡或玩家剪贴板发送数据。

扫描沿原版先查最近实体，再决定返回生物、矿车或方块；不会提前忽略更近的
其他实体。液体和可替换方块的扫描继续触发可取消的破坏事件，但不实际破坏。

玩家对象支持世界、位置、游戏模式、生命、经验和物品栏操作；计分板对象支持
队伍、目标和分数。世界对象支持维度、天气、时间、出生点、声音、方块、方块
实体 NBT、物品和流体操作。每次调用都会重新检查访问权限。

现代维度使用稳定保存的数字 ID，并可按资源名称查找；维度名称返回原版对应的
名称部分。方块状态索引保持零为默认状态，可通过 `getMetadata` 往返；现代完整
状态已经包含连接属性。NBT 使用原来的 `{type, value}` 表，并支持现代长整数
数组。物品 NBT 同时支持现代组件格式。

流体操作只访问方块实际提供的储罐能力；没有储罐时返回 `nil, "no tank"`，
不会把空气或地面流体当成储罐，也不会借此在世界中放液。

天气开关只改变对应标志，不重设天气计时；原光照查询不额外扣除夜间天空亮度。
远程连接、卡地址和绑定数据可随真实物品保存并重新接线，卸卡时从调试网络移除。

## 有限验收

`DebugCardContract` 只在隔离测试世界内操作自有 Case、卡、玩家及方块区域。
授权通过真实白名单命令，绑定通过实际物品右键，操作通过公开 SDK 和真实
Case Context 调用。场景包含权限撤销、玩家和世界对象、计分板、NBT、原命令
坐标与权限、远程连接和调试消息。结束后移除测试授权、玩家和自有场景。
剪贴板在远程客户端中的显示仍归共同客户端验收。
