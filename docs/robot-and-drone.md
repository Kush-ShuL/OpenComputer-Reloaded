# 机器人与无人机

机器人和无人机沿用 OpenComputers 的组装方式。处理器、内存、固件、升级和容器决定它们能做什么；物品的等级会影响名称颜色。创造模式提供已装好硬件的版本，普通机器人和无人机仍需按原配方组装。

## 使用机器人

放置时，机器人朝向与玩家一致。空手潜行右键可以开机，普通右键打开库存与屏幕。工具放进工具槽，物料放进内部库存；安装的容器提供可更换的硬件槽。安装库存、流体、悬浮等升级后，原有对应功能才会可用。

Lua 中使用原来的 robot 库。移动、转向和工具操作会消耗能量或占用执行时间。受保护的方块、取消的交互事件、不可采集的方块以及工具条件都会影响实际操作。移动被取消时退还移动费用；移动后仍使用同一台电脑和同一份库存。

transferTo 可以合并同类物品；数量足够时也能交换两种不同物品的整个堆叠。向地面丢物品被其他模组取消时，物品回到真实库存。吸取地上物品会经过正常拾取条件，成功结果是实际吸取数量。打掉方块或实体产生的物品通过真实掉落实体进入库存，工具损耗继续经过公开事件，经验升级可以降低损耗。

复制创造模式机器人会重新生成屏幕身份，避免多台复制品共用一份屏幕。拆下机器人前保存硬件和电量；移动中的旧位置保留原来的短暂残影。

## 使用无人机

对准方块使用无人机物品即可放出，出现位置取决于实际点击的面和位置。普通右键打开界面；潜行右键启动，潜行持扳手右键可以拆下。拆下时会掉出库存，并把控制器本地电量保存到无人机物品。电池升级的状态仍保存在对应硬件中。

Lua 中使用 component.drone：

    local drone = require("component").drone
    drone.setStatusText("Hello")
    drone.setAcceleration(1)
    drone.move(1, 0, 0)

移动目标以四分之一个方块为单位，move 累加目标偏移。加速度范围为每秒平方 0 至 2 方块，最大速度为每秒 8 方块。无人机运行时追踪目标；停机后受重力影响。碰撞会影响实际速度，位于实心方块中时会尝试脱困。

状态文字最多显示两行，每行十个字符。颜色回调保留原版整数值。目标、速度、库存、选中槽、所有者、状态文字、硬件与电脑状态继续随世界保存；物品拆装和世界存档保留的信息范围沿用原版。
