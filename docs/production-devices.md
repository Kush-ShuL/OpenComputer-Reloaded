# 装配、拆解与磁盘阵列

本族覆盖 D03 装配机、D11 拆解机和 D33 磁盘阵列。语义来源仅为
MightyPirates/OpenComputers 固定提交 `258943363ea8fc4ef14948e6bc6f67375061580c`
中对应方块、方块实体、容器、`RaidData` 及完整装配和拆解模板，保留上游许可证与归属。

D03 保留 22 个槽位：基础物品、三个容器槽、九个升级槽和九个组件槽。选择模板后
按宿主驱动检查槽位和等级，验证 CPU、内存及复杂度，显示原缺件提示并应用装配
黑名单。内置模板覆盖各等级机器人、无人机、平板和微控制器；外部 IMC 模板继续
通过同一验证、生产和耗能流程。开始时消费一次输入，保存实际待交付物品与总能量、
剩余能量，按配置周期和功率推进。`status`、状态感知及界面以剩余能量判断是否正在
装配；零耗能任务等待下一次交付时仍保护库存，避免新材料覆盖待交付成品。
顶部不接入 OC 网络或外部电力，其余面沿用原连接规则。
装配机和拆解机均恢复原比较器输出：工作中为 15，可以工作为 10，其他状态为 0。
物品提示保留装配用途和实际配置的拆解损坏概率，三种机器均沿用原禁止生物生成的规则。

D11 保留单个输入槽、禁止拆解标记、配方材料恢复，以及随机材料和保证掉落两条
模板输出路径。内置特殊拆解覆盖机器人、无人机、服务器、平板、微控制器和导航
升级；导航升级替换配方中的地图为原存储地图，保留地图 ID 和物品组件。队列按项
计算能量，保留进度、能量缓冲、创造模式快速处理与配置损坏概率。
查找制造原料时先跳过以成品自身为输入的自重制配方，再继续查找制造配方，
避免地图更新配方抢先匹配而使导航升级的拆解材料变成空队列。
输出按六个方向依次送入邻接库存，每面每次最多 64 个，余物向上掉落。
顶部禁止外部电力输入，但原普通 OC 环境节点仍可从顶部连接，二者不再混为一项。

D33 接受三块真实硬盘，只有三盘齐全时提供一个网络可见的快速文件系统，容量为
三盘容量之和。组阵会清除成员盘的锁定和非托管标记并格式化成员盘；拆下任意成员
会销毁阵列文件系统，重新补齐会建立新的阵列。标签上限 16 个字符，完整阵列使
比较器输出 15，并保留磁盘存在、活动指示和分析器入口。

完整机柜掉落携带成员盘、阵列文件系统信息及标签，放置后恢复同一阵列；拆成员与
搬动完整机柜保持不同处理。方块实体重新加载会恢复可初始化状态，重新接入网络，
不再被上次卸载留下的标记阻止。`RaidData` 的三个原持久字段及现代物品组件读写
已匹配；共享文件系统实现由 C11/D14 的同源迁移维护，本族不另建存储实现。
