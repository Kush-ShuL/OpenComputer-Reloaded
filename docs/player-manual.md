`client/renderer/markdown/` 片段与内置图像提供者，以及公开 manual API。
保留上游署名、文档、图片和许可证，运行实现使用 Java。

## 物品与上下文

普通空中使用打开当前历史位置；潜行空中使用先重置到首页。
使用有文档的方块时打开其上下文页并重置原历史；带自身普通交互界面的方块沿
原游戏交互顺序，需要潜行来绕过其普通界面。没有路径的方块走普通物品回退。
物品保留版本号、原说明、短节点地址、带地址单件堆叠及禁止书附魔。
所有打开动作只接到物理客户端，专用服务器不创建手册屏幕。

## 内容、路径与扩展

保留公开 PathProvider / ContentProvider / ImageProvider / TabIconRenderer。
路径和内容按注册顺序选择首个非 null 结果；OC 自身资源提供者仍在最前。
图像提供者按相反注册顺序匹配前缀，新提供者返回 null 时继续回退。
各类提供者抛错沿原行为记录日志并继续查询，不改变 SDK 方法或发布坐标。

`%LANGUAGE%` 使用当前语言，缺页时回退英文。路径保留根路径、相对目录、
`.` / `..` 和 Windows 分隔符规范化。原 `#redirect` 支持相对目标、语言变量
和循环检测；不再为一条有效重定向链额外设置 128 页上限。
内置资源查询统一小写，以适应现代 Minecraft 资源名；根构建同时把旧源码文档
和图片路径规范为小写，原源图及署名不变。扩展提供者本身收到的路径仍保留其
大小写语义。

已有地毯电容缺页回退仍保留，并补齐旧 `cu` 描述符到 `controlunit.md` 的回退。
资源包显式提供的原路径页面优先于这些回退。

## 排版与输入

保留标题、粗体、斜体、删除线、内联代码、普通链接、图像、嵌套格式、按行布局、
列表续行缩进、标点软换行与长词硬换行。任意数量的标题 `#` 都按原字号公式
缩放，不只接受前六级。代码使用 OC 自己的配置字体、Unicode/CP437 图形和
原蓝色，通过新增字符串入口复用现有字体图集；不伪造文本缓冲或改写终端的
缓冲渲染/缓存路径。原 Markdown / IGWMod 文本导出能力也由文档类保留。

页面保持 256×192 窗口、230×176 内容区和原滚动条。正文与图片裁剪到内容区。
滚轮、滚动条拖动、跳跃键/右键返回、背包键关闭均保留；历史逐页保存滚动位置，
关闭后重新打开仍停在原位置。关闭期间的公开 navigate 仍按原行为压入历史，
打开期间相同页不重复入栈。原七个可见侧标签仍可点击，更多标签可滚动访问。
滚动条悬停或拖动显示原百分比。

链接保留有效绿色/失效红色及 500 毫秒悬停渐退；同一逻辑链接的换行片段共享
高亮，不会把文内所有重复 URL 一起高亮。相对页链接打开新页，外部 HTTP(S)
链接使用现代 Minecraft 链接界面，原链接目标仍保留。页内锚点作为现有扩展保留。

## 图片与交互式内容

原纹理、item、block、oredict 四类都真实绘制图像，不以文本代替。
图像按自然尺寸居中，超出页宽时等比缩小；图像单独成行时不额外插入空白行。
保留图像标题/自定义提示及悬停半透明白色高亮。
InteractiveImageRenderer 获得自身坐标和点击，返回 true 时消费点击，false 时
继续处理外层链接。未知/损坏图像显示原缺失图标与对应提示。

item/block 接受现代注册名，并把原 OC 七个 Delegator 注册族的 `@metadata`
按 PIN 的真实注册顺序映射到现代物品；Chamelium 方块的旧颜色值映射为现代
BLOCK_STATE。原 tablet/debug-card/drone 页保留的旧共享 item 68/73/84 引用有
对应别名；没有来源证据的旧 item 23 不猜测为别的物品，继续显示缺失提示。
旧 serverRack / switch / accessPoint 图像名称对应现代 rack / relay。

OC OreDict 图像先查询对应的真实现代物品标签，循环其全部候选；没有标签候选
时再查明确的 OC 描述符。普通矿物旧词典名映射现代 c: 标签，另保留现代 tag:
图像入口。候选每秒轮换，使用真实物品模型。尚未存在的原设备保持缺失提示，
不会用不相干的物品冒充。
