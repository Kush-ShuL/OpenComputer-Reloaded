# 拴绳、活塞与牵引光束升级

语义来源仅为 MightyPirates/OpenComputers 固定提交
`258943363ea8fc4ef14948e6bc6f67375061580c` 中的 `UpgradeLeash.scala`、
`UpgradePiston.scala`、`UpgradeTractorBeam.scala`，及其原物品、驱动、方向和背包工具。
保留上游许可证与归属，全部使用 Java 实现。三个组件均恢复原回调文档和网络可见性。

D50 拴绳升级仅安装于实体宿主。`leash(side)` 使用世界六方向，不随宿主旋转；
搜索宿主方块至指定方向两个方块的联合范围，直接尝试第一个可拴绳的生物，最多记录
8 个 UUID。达到上限优先返回 `nil, "too many leashed entities"`；没有目标返回
`nil, "no unleashed entity"`，方向越界抛出 `invalid side`。成功暂停 0.1 秒，
无额外能耗或合成的玩家交互事件。实体跟随真实宿主，移动由原生拴绳行为处理。
`unleash()` 及自身节点断开会释放五格扩展范围内仍属于本宿主的记录目标，不掉落拴绳，
然后清空记录。`leashedEntities` 字符串列表持久化；加载后的首次环境更新重新连接附近
已记录的生物，移除找不到的 UUID 并记录数量。

D53 普通、粘性活塞共用原生移动器及其方块黏连和数量限制，普通活塞只提供 `push`，
粘性活塞另有 `pull`；`isSticky()` 返回实际类型。省略方向默认为前方，显式 `nil`
仍按整数参数报错。无人机接受六个世界方向；旋转宿主接受本地前、上、下并转换为
世界方向，其余有效方向报 `unsupported side`，范围外报 `invalid side`。
平板向下且玩家眼高超过一格时，起点下移一格。拉动时相邻格必须为空气或可被活塞
破坏，否则返回 `false, "path is obstructed"`；原生移动失败返回 `false, "move failed"`。
沿用原版不扣 `pistonCost`、不合成方块破坏事件的行为。成功播放十五格范围的原活塞
声效，音量 1.5、音高 1，并暂停一个刻。组件无额外动作状态需要持久化。

D58 `suck()` 在宿主方块向三轴各扩展三格的范围内，从存活且无拾取延迟的掉落物中
用世界随机源选一个，只尝试这一项；失败不会继续搜索其他物品。机器人、平板调用
真实玩家拾取入口，保留原生拾取规则与 NeoForge 拾取事件。无人机直接插入自身背包，
按选中槽至末尾、再从首槽至选中槽前的顺序，单次最多 64 个。只有实际数量减少或
掉落物消失才返回成功，暂停经配置修正的 `suckDelay` 并播放原编号 2003 效果。
无额外能耗或持久状态；设备型号保留 `T313-K1N.3515`。

物品、驱动及宿主更新、保存、卸载入口均已接入；粘性活塞的环境类型映射已恢复。
Windows Java 21/NeoForge 构建通过。
