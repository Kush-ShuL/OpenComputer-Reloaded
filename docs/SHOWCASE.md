# OPEN LAB 实验基地

这是一个可以保存、继续游玩的创造模式基地。中央通道连接八个体验区，设备已经
装好硬件、接好各自的线路。正在工作的示例由游戏内的 Lua 计算机驱动。

进入后沿中央通道向前走。入口左边的箱子和背包里都有手册、分析仪、系统盘和
备用硬件。右键手册阅读；手持分析仪右键设备，可以查看地址、能量与网络信息。

| 体验区 | 可以做什么 |
| --- | --- |
| 总控制室 | 右键大屏幕或键盘。按 **1** 启停物流，按 **2** 启停机器人，按 **3** 开关全息。工作站通过无线网卡回传真实状态。 |
| 地质扫描台 | 查看屏幕上的密度扫描；玻璃地板下放着四种矿石样本，每五秒重新扫描。 |
| OpenOS 入门桌 | 右键键盘输入 `help`。输入 `install`，按提示把系统装到硬盘；箱里另有 Plan9k 系统盘可换。 |
| 物流与红石 | 左箱每秒向右箱搬一件物品，旁边红石灯闪烁。补充左箱可继续搬运；在屏幕里按空格或在总控按 1 暂停。 |
| 机器人巡航轨道 | 机器人在围栏内往返六格。右键查看它的画面；空格或总控按 2 启停。它有工具和可用库存。 |
| 机架与无线终端 | 机架中有服务器、终端服务器和软盘驱动器，旁边的 RAID 已装三块硬盘。使用背包里的“已绑定无线终端”远程访问服务器并输入文字。 |
| 数字制造工坊 | 看旋转的全息建筑，右键打印机领取实际打印的纪念模型。材料箱有变色合金和黑色染料；装配机已放好一套入门硬件，拆解机演示回收。 |
| 移动设备与充电 | 充电器中有可取出的平板，箱中另有平板、无人机、机器人与悬浮靴。平板右键进入 OpenOS；附近装备可以充电。 |

先从 OpenOS 桌开始，可以输入：

```sh
help
components
lua
```

进入 Lua 交互环境后，试试：

```lua
print("你好，OpenComputer！")
local component = require("component")
print(component.gpu.getResolution())
```

按 **Ctrl+D** 返回命令行。想修改自动化示例时，可以查看对应设备里的 EEPROM。
全部示例源码还保存在该存档的 `opencomputers/showcase/programs` 中，方便对照。

基地使用创造级机箱、服务器和机器人供电，方便先体验用法。换成生存级设备时，
再按照手册配置能源与硬件即可。各工作间的设备网络相互独立，总控制室通过
无线通信控制它们；拆线、移除网卡或关闭计算机后，控制室会显示设备离线。
