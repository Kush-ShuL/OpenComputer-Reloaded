# 玩家工具与装配材料

本族语义仅来自 MightyPirates/OpenComputers 固定提交
`258943363ea8fc4ef14948e6bc6f67375061580c` 的 `common/item/` 对应类、
`traits/Delegate`、`SimpleItem`、`ItemTier`，以及原屏幕、文本缓冲和旋转路径。
保留上游署名与许可证，现代实现使用 Java。

## T01 分析仪

保留 Analyzable → SidedEnvironment → Environment 的分析顺序；能力附着的现代
环境沿已有能力桥承接。显示机器错误、组件使用量、用户、本地/网络电量、
组件名与地址，假玩家不会收到节点诊断。机器人分析继续只触发一次
RobotAnalyzeEvent，并使用真实机器人控制器；已有条码升级运行证明直接复用。

正面使用屏幕时，普通使用粘贴物品内 `oc:clipboard`，潜行使用按真实字体和
合屏坐标复制选中的文本行。越界行或空行会清除旧内容。潜行在空中使用清除
剪贴板，同时保留物品其他数据。地址响应保留 Ctrl 复制和反馈，现代聊天还支持
点击地址复制。已有手持分派和服务端请求检查保留，不改写载荷或字体系统。

本次补齐原 Delegate 的带地址单件堆叠、禁止书附魔，以及正确展开 `[nl]` 的
物品说明和短地址。普通行复制、显示与远程载荷的共同验收归 C19 / C21 / C23。

## T02 扳手

保留单件、无耐久损耗、潜行绕过方块激活及公开 Wrench 模拟/使用约定：模拟只
判断适用性，实际使用挥动主手。旋转先检查区块已加载和世界修改权限，沿所点击
轴使用原方向矩阵；键盘拒绝旋转，屏幕保留原十二朝向规则，其他方向属性按其
合法值旋转。旋转后通知当前方块和邻居，并按变化后的面重新接线，移除旧封闭面
残留边。

充电器也遵循原 SimpleBlock 的竖轴旋转：顶/底面可旋转，侧面回落到充电器自身
的扳手反相操作。没有为旋转增加消耗、延迟或另一项物品编辑权限。
原禁止书附魔、说明和短地址提示一并保留。
IC2 工具箱接口归 I09 的现代集成，不以删除它改变原范围。

## T04 网络调试器

网络调试器只接受真实服务端玩家，假玩家与客户端本地调用返回 PASS；没有新增
管理员门槛。点击 SidedEnvironment 连接所点面的节点，普通 Environment 连接其
节点，其他方块仅断开监视器。空面的有效环境仍走原独立网络重连路径。
同次服务端运行中的监视器保留自己的节点身份；重新点击不会为普通断开销毁该
身份。服务端结束时释放监视器，避免单人换档保留旧世界引用。

监视器把节点连接、移除及网络消息写入原 NETWORK DEBUGGER 日志，不附加 Lua
组件、费用或耐久。物品按原 Delegate 使用普通稀有度，保留说明、短地址、带
地址单件堆叠和禁止书附魔。本项不修改 D10 调试卡的任何组件或权限。

## T05 纹理选择器

使用方块时，由客户端读取其实际方块模型的粒子纹理名称，输出原本的本地化
纹理名称消息；服务端不访问渲染类。普通和潜行使用相同，没有额外损耗、权限
或持久状态。原物品说明、地址提示、堆叠及禁止书附魔已补齐。
实际客户端模型/聊天显示归 C20 / C23，本批没有注入自动界面操作。

## T16 材料、机壳与墨盒

普通材料保持原注册身份、64 堆叠和合成用途，带节点地址时按原 Delegate 限制
单件。一级至三级微芯片恢复各自稀有度，共用原 microchip 说明；card、cu、
chipdiamond 分别映射回原 CardBase、ControlUnit、DiamondChip 说明。
ArrowKeys / ButtonGroup 继续没有独立说明，不显示不存在的翻译键。

Grog 保留 32 刻饮用，结束时给玩家施加原五种效果，并卸载已安装的纳米机器，
然后消耗一件；非玩家不会被这条饮用完成分支消耗。Chamelium 保留 32 刻吃用和
原隐身/失明效果；禁食配置下右键仍返回原 SUCCESS，但不开始吃用。
两者保留原物品消耗规则，没有另加创造模式豁免。

满墨盒及空墨盒保持单件，满墨盒作为合成原料留下一个空墨盒。
无人机、微控制器和平板空机壳按原等级使用普通/少见/稀有/史诗稀有度、
64 堆叠、各自说明与高级等级提示；只有有节点地址时才成为单件。
所有这些 Delegate 物品拒绝书附魔。

Chamelium 方块保持黑色默认状态及原十六色。掉落和选取把实际方块颜色传给
现代 BLOCK_STATE 物品组件，黑色恢复普通默认物品；保留原可空手掉落的性质。
已有染色合成与装配配方仍由共同配方实现负责。
